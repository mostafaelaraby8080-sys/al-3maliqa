# موقع شركة العمالقة للتسويق العقاري والمقاولات — دمياط

## التشغيل السريع

1. ثبّت Node.js من nodejs.org
2. افتح مجلد `backend` ونفّذ:
   ```
   npm install
   npm start
   ```
3. افتح المتصفح: http://localhost:3000

## بنية المشروع

- `index.html` — الرئيسية (سلايدر + خدمات + عقارات مميزة + آراء عملاء)
- `about.html` — من نحن (قصتنا + قيمنا + رحلتنا)
- `services.html` — الخدمات الست بالتفصيل
- `properties.html` — العقارات مع فلاتر (تُجلب من `/api/properties`)
- `contact.html` — نموذج تواصل متصل بالباك إند + خريطة
- `css/style.css` — التصميم (ذهبي داكن كالموقع الأصلي)
- `js/main.js` — كل تفاعلات الواجهة
- `backend/` — باك إند Node.js + Express + SQLite

## قبل النشر

- غيّر أرقام التليفونات والإيميل في كل الصفحات
- استبدل الصور بصور عقارات الشركة الحقيقية
- أضف حماية (JWT) على لوحة الرسائل
