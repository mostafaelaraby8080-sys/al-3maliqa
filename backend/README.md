# باك إند موقع شركة العمالقة (Node.js)

## التشغيل

```bash
cd backend
npm install
npm start
```

ثم افتح المتصفح على: **http://localhost:3000**

## الـ APIs المتاحة

| Method | المسار                | الوظيفة                                                       |
| ------ | --------------------- | ------------------------------------------------------------- |
| GET    | `/api/properties`     | كل العقارات (اختياري: `?category=شقق` أو `?deal=للإيجار`)     |
| GET    | `/api/properties/:id` | عقار واحد بالتفاصيل                                           |
| POST   | `/api/contact`        | استقبال رسالة نموذج التواصل `{name, phone, service, message}` |
| GET    | `/api/messages`       | عرض كل الرسائل الواردة                                        |
| DELETE | `/api/messages/:id`   | حذف رسالة                                                     |

## ملاحظات

- قاعدة البيانات SQLite تُنشأ تلقائياً (`alomalaqa.db`) مع عقارات تجريبية.
- السيرفر يخدم ملفات الواجهة أيضاً، فلا تحتاج سيرفر ثانٍ.
- قبل النشر: غيّر أرقام التليفونات في صفحات HTML، وأضف مصادقة (JWT) على `/api/messages`.
